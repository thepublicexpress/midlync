## 🔄 Account Recovery

### Forgot Password?

1. Go to login page
2. Click **"Forgot Password?"**
3. Enter email address
4. Check email for reset link
5. Click link to reset password
6. Set new password
7. Login with new password

### Account Suspended?

1. Check email for suspension reason
2. Contact support@midlync.com
3. Provide account details
4. Explain your situation
5. Wait for admin review
6. Account reactivated if eligible

### Need Help?

**Live Chat:**
- Click chat icon in dashboard
- Available during office hours
- Average response: 5 minutes

**Email Support:**
- Send detailed message
- Include account email
- Describe issue clearly
- Expected response: 24 hours

## 🚨 Important Notes

### Privacy & Security
- Never share your password
- Logout after using shared computers
- Report suspicious activity
- Keep personal info updated
- Use strong passwords (16+ chars)

### Payment Safety
- Only pay through platform
- Use verified payment methods
- Check SSL certificate (🔒)
- Don't share OTP/CVV
- Review transaction receipts

### Dispute Resolution
- Document all communications
- Save order receipts
- Report issues promptly
- Provide evidence (photos/tracking)
- Follow admin guidance
